# Prompt 3: Revise once

Return to the drafting chat or use another fresh chat. Provide the complete material again.

```text
Revise the draft once using the original brief, sources and review below.

Apply each supported correction. Preserve accurate content. Use only the supplied evidence and keep the source IDs exact. Do not guess, invent completion or ownership, imply approval, or present a conditional target as a commitment. Surface unresolved missing information and the human decision required.

Return:
1. the corrected update only
2. a short correction report listing what changed and any review point you did not apply, with the reason

Stop after this one correction round. Do not send, publish or update any external system.

ORIGINAL BRIEF
[Paste the complete drafting prompt.]

SOURCES
[Paste the complete context and sources, with the original IDs.]

ORIGINAL DRAFT
[Paste the reviewed draft.]

REVIEW
[Paste the complete review.]
```

The correction report supports human checking. It is not approval to use the update.

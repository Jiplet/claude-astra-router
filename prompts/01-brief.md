# Prompt 1: Draft the update

Use this in a fresh chat with the source material below it.

```text
You are drafting a workplace update for a professional audience.

Write an update of no more than 180 words, accurate as at [DATE]. Use only the supplied sources. Add the source ID in square brackets after every material claim, for example [S2]. If sources conflict, prefer the most recent dated authoritative record and state the conflict. Do not guess, imply approval, invent an owner or turn a target into a commitment.

Include:
- current status and what has been completed
- the next target, including any dependency or condition
- unresolved uncertainties or missing information
- the human decision or confirmation required

Do not send, publish or update any external system. Return draft text only.

CONTEXT
[Paste the audience, purpose and tone here.]

SOURCES
[Paste each complete source with its source ID, title and date here.]
```

For the worked example, set `[DATE]` to 14 September 2026 and copy the context and all sources from [sources.md](../examples/weekly-update/sources.md) into `CONTEXT` and `SOURCES`. Keep the labels unchanged.
